# Drop your real assets here

The site picks these up automatically. No code changes needed.

| File | Used for |
| --- | --- |
| `app-screenshot.png` (or `.jpg`, `.jpeg`, `.webp`, `.avif`) | The screen of the hero phone. Use a portrait phone screenshot, about 1170 x 2532. WebP under 300 KB is ideal. |
| `logo.svg` (or `.png`, `.webp`) | Replaces the placeholder mark in the navbar and footer. |

Remember to update the `alt` text in `src/content/site.ts` once the real screenshot is in.
